# 💳 Credit Scoring Model using Machine Learning

## 📌 Project Overview

This project was developed as part of the **CodeAlpha Machine Learning Internship**.

The objective is to build a **Credit Scoring Model** that predicts a customer's creditworthiness based on financial information using supervised machine learning algorithms. The project includes data preprocessing, exploratory data analysis, model training, evaluation, and performance comparison.

---

## 🎯 Objective

To classify customers into different credit risk categories using historical financial data and evaluate the performance of multiple machine learning models.

---

## 📂 Dataset

**Dataset:** German Credit Data (`german_credit_data.csv`)

The dataset contains customer financial information such as:

* Account Status
* Credit Duration
* Credit History
* Purpose
* Credit Amount
* Savings Account
* Employment Duration
* Installment Rate
* Personal Status
* Age
* Housing
* Existing Credits
* Job
* Telephone
* Foreign Worker
* Credit Risk (Target Variable)

---
